# Prerequisites — Foundational Concepts

Before starting the main curriculum, make sure you're comfortable with these three foundational areas.

This section is **optional** but highly recommended if you're new to any of these topics.

---

## What You Need to Know

### 1. Basic Programming (Python, JavaScript, or Similar)

- Variables, data types, and basic operations
- Functions and how to call them
- Loops and conditionals (if/else, for, while)
- Working with lists, dictionaries, and objects
- Basic error handling and debugging

**Time to review**: 2-4 hours

**Go to**: [Basic Programming](01-basic-programming.md)

---

### 2. How HTTP Requests Work

- What is HTTP (HyperText Transfer Protocol)?
- Request/Response model
- Methods: GET, POST, PUT, DELETE
- Status codes (200, 404, 500, etc.)
- Headers and how browsers communicate with servers
- JSON and data formats

**Time to review**: 1-2 hours

**Go to**: [HTTP Requests](02-http-requests.md)

---

### 3. Command Line Basics

- Opening and navigating the terminal/command prompt
- Basic commands: `cd`, `ls`, `pwd`, `mkdir`, `rm`
- File paths (absolute and relative)
- GREP (searching for text)
- Running programs from the command line
- Understanding exit codes and errors

**Time to review**: 2-3 hours

**Go to**: [Command Line Basics](03-command-line-basics.md)

---

## Do You Need This Section?

### ✅ Start with Prerequisites if:

- You're new to programming or haven't coded in years
- You're unfamiliar with HTTP or web APIs
- You're uncomfortable with the command line
- You want a quick refresher before diving in

### ⏭️ Skip to Main Curriculum if:

- You code regularly in Python, JavaScript, Java, or similar languages
- You've built or consumed APIs before
- You're comfortable navigating directories and running CLI commands
- You want to jump straight into backend engineering

---

## Time Estimate

- **All three sections**: 5-9 hours total
- **One section**: 1-4 hours
- **Quick refresher**: 1-2 hours per topic

## What's NOT Covered Here

This section assumes zero knowledge of:
- Docker, containers, or Kubernetes
- Databases or SQL
- Web frameworks
- Cloud platforms or AWS
- Distributed systems

Everything above will be covered in the main curriculum starting with [Docker & Containers](../docker/index.md).
